# Privacy Policy

Buck Workflow is an open-source collection of Codex skills. The skills operate in the repository and services that a user explicitly authorizes Codex to access.

Buck Workflow does not operate a hosted service, collect analytics, create user accounts, or independently transmit repository content. Individual skills may use tools already configured for the user's Codex environment, such as GitHub, web research, or a local shell. Those tools and services are governed by their own privacy policies and the user's configured permissions.

For privacy questions or reports, open an issue at <https://github.com/evilbuck/buck-workflow-pi/issues>.
