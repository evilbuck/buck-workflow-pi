# b-which router generated from the catalog

A `b-which` router skill that picks the right skill for the task at hand, **generated from the skill catalog** rather than hand-maintained — so it stays correct as skills are added. Per the umbrella item (`mattpocock-adoptions.md`), promote this one if Tier 3 lands, since every new skill widens the selection problem it solves.
