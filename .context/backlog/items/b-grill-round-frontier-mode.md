# b-grill round-frontier mode

An upstream `b-grill` mode that runs grilling in successive rounds, each round pushing the frontier of open questions deeper until the plan either converges or exposes a phasing boundary.

Deferred from the 2026-09-10 mattpocock/skills adoption plan ([plan-mattpocock-findings-remediation.md](../../2026-09-10.mattpocock-adoption/plan-mattpocock-findings-remediation.md), Tier 4): the existing `b-grill` / `b-grill-auto` / `b-grill-with-docs` modes already stress-test plans adequately; round-frontier orchestration is refinement, not missing coverage. Not on the audit's rejected list.
