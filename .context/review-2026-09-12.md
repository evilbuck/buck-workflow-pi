- **Standards axis worst finding** (parallel agent `StandardsReview2026-09-12`): `LoopContext` types `runDir: string | null` and `state: RunState | null` (loop.ts:126-131), then 19 non-null assertions (`ctx.state!` and `ctx.runDir!`) stand in for post-`initializeRun` narrowing throughout the loop (e.g. loop.ts:651, 658, 676). `freshContext` always constructs those fields as `null`; `initializeRun` is a convention, not a type gate. This is the Temporary Field / late-init pattern; a discriminated state (`{ runDir: null; state: null } | { runDir: string; state: RunState }`) typed through subsequent helpers would remove the `!` cascade.
