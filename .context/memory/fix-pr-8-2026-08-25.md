# PR #8: contain OMP plan artifact paths

PR: https://github.com/evilbuck/buck-workflow-pi/pull/8

## Validation

| # | Claim | Verdict | Disposition |
|---|---|---|---|
| 1 | `local://../../sensitive-file` can escape session `local/` and copy a host file into `.context/`. | valid | Fixed by resolving against `local/` and rejecting paths outside it. |

## Fix

`resolvePlanDiskPath` now accepts only non-empty `local://` paths, resolves them
from the session `local/` root, and rejects absolute paths plus any resolved
path that escapes that root. The integration regression test proves a traversal
cannot create an artifact or marker entry.
