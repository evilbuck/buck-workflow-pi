## Fix

`resolvePlanDiskPath` now:

1. Rejects lexical escapes (`..`, absolute, empty relative).
2. Returns `null` when the candidate does not exist.
3. Canonicalizes `localRoot` and the candidate with `realpathSync()`.
4. Rejects canonical paths that escape the canonical root.
5. Returns the canonical path so `readFileSync` cannot follow an out-of-root link.

In-root symlinks still persist.
