## Root cause (finding #1)

`RepoSignals.files` is a list of **file paths**, not directory names: `walkFiles` only
`files.push(relative(root, absolute))` on `entry.isFile() || entry.isSymbolicLink()`
(line 100); directories recurse via `visit(absolute)` and are never listed. So
`signals.files.includes("tests/e2e")` / `.includes("spec/system")` always returned
`false`, and `functional_test_cmd` silently resolved to `null` for python and ruby.
Every sibling branch in `resolveFunctionalSignals` (typescript/go/rust) uses
file-pattern/prefix matching — the python/ruby branches were the only ones using
exact directory-name `.includes()`.

Fix: `existsSync(join(signals.root, "<dir>"))` — matches the directory-existence
intent and handles empty test dirs. `existsSync`/`join` already imported.
