# b-capture

Note-taking mode. User dumps; agent scribes via subagent; polish waits until the user says so. Topic-agnostic — not a research skill and not domain-specific.

Shipped as skill + thin prompt + OMP `commands/` symlink. Consolidated three overlapping managed skills (`incremental-dictation-research-notes`, `rolling-dictation-research-capture`, `parallel-research-capture`) into this one.

Not `/b-research` (agent investigates and synthesizes). Not `/b-explore` (agent traces the codebase).
